## État actuel (22 mars 2026 – après résolution)
- Le site est **opérationnel en HTTPS** avec Nginx + PHP‑FPM.
- Le problème de redirection vers `error404.html` était dû à une mauvaise gestion des réécritures dans Nginx, qui s’appliquaient même aux fichiers PHP existants. La correction a consisté à :
  1. Déplacer toutes les règles de réécriture dans un bloc `location @rewrite`.
  2. Utiliser `try_files $uri $uri/ @rewrite;` dans le bloc `location /`.
  3. Conserver le bloc `location ~ \.php$` pour le traitement PHP.
- Le fichier `index.php` contenait temporairement `var_dump($chemin_absolu); exit;` pour un test ; ces lignes ont été supprimées.
- La base de données est correctement remplie (tables `site_menu`, `categories_blog`, etc.).
- Le certificat SSL Let’s Encrypt est installé et fonctionnel.
- **phpMyAdmin** est accessible via `https://pma.offipro.net` (configuration Nginx disponible mais doit être activée avec `ln -s` si ce n’est pas déjà fait).
